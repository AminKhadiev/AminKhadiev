### 🌩️ Neural-Infra Monitor
Система предиктивного мониторинга инфраструктуры. Предсказывает инциденты по паттернам метрик CPU/RAM еще до того, как они станут критическими.
*   *Стек:* Python, Llama.cpp, Prometheus API, React + Three.js
*   [🔗 Demo](https://neural-infra-demo.yoursite.ru) • [Исходный код](https://github.com/AminKhadiev/neural-infra-monitor)
<br><br>

### 🛠️ TerraformGPT CLI
Утилита командной строки, генерирующая готовые модули Terraform по запросу на естественном языке.
*   *Стек:* Go, LangChain, GPT-4o, tflint integration
*   [📦 Releases] • [Исходный код](https://github.com/AminKhadiev/tfgpt-cli)
<br><br>

### 🐳 ContainerScape
Интерактивная карта работающих контейнеров в реальном времени. Нагрузка на CPU = скорость движения «медузы», потребление RAM = её размер.
*   *Стек:* Moby API, WebGL, TinyML
*   [🎮 Live Playground](https://containerscape.vercel.app) • [Исходный код](https://github.com/AminKhadiev/containerscape)
